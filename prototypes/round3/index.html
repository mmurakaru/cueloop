cueloop · round 3 — feature-rich Ledger

Three variants building on the chosen Ledger layout, each going deeper on one feature cluster. All share Workspace / Focus / Guided / Split modes, System / Light / Dark, an optional textured canvas, and the keyboard grammar (⌘⏎ = approve-or-send, J/K nav, v viewed). Press ? inside any concept.

design system: hex.tech · cloudflare.com · e2b.dev — feature set distilled from prior-art review tooling, made cueloop's own

  1. 01 Ledger — Markupselect · comment · redline
    The annotation toolset in depth: Select/Comment/Redline input modes, label tags (Alt+1..5), "looks good", conventional-comment labels with blocking flags, and code suggestions in diffs.
  2. 02 Ledger — Console⌘K · ⌘,
    Settings + command surface: a working Settings dialog whose Diff tab genuinely restyles the live diff (split/unified, word/char, intensity, fonts), plus a fuzzy command palette.
  3. 03 Ledger — ContextStatus/Tree · versions
    Navigation & revisions: Status-vs-Tree sidebar, changed-first tree expandable to the full repo, all-files continuous scroll with mark-viewed, word/char diff depth, and a plan version browser for agent resubmits.
These are intermediate, feature-rich Ledger variants. Next: atomic-feature deep-dives (sidebar, edit mode, diffs, settings) prototyped in isolation toward the final product. Round 1 is in ../index.html; round 2 in ../round2/index.html.

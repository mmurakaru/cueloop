The Tree view shows the revisions, comments, edits, and Messages in a Thread.
Use it when you need to return to earlier work or explore another direction.

## Checkpoints

A checkpoint names the current point in the Thread. Add one before a risky
rewrite so you have a clear place to return to.

## Moving back

Move back to an earlier point to continue from there. Later work stays in the
Tree view. It is not deleted.

## Branches

A branch starts another line of review from the current point. Comments and
edits stay with that branch. Switch back to `main` to return to the agent's
original line.

## Forks

A fork creates a new Thread from the current point. It keeps the visible
revisions, comments, checkpoints, and participants.

Use **Fork and share** when two people need separate comment threads.

## From the command line

The [commands reference](/docs/reference/commands/) lists the checkpoint,
branch, navigation, and fork commands.

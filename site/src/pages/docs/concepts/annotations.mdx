An annotation is feedback attached to a marked range of text. Select the text,
type your note, and save it. Replies stay grouped with the first annotation.

## When the text changes

cueloop uses the quoted text to find an annotation after a revision. It only
reattaches the annotation when the match is safe.

If the text no longer matches, the annotation remains visible as outdated. It
is never silently moved or deleted.

## When you send feedback

Your next Message includes new and edited annotations. Comment sends them while
keeping the Thread open. Approve and Request changes send them with the review
result.

Annotations from teammates also join the Thread without replacing your own.

See [Keyboard & mouse](/docs/reference/keyboard/) for marking, commenting, and
replying controls.

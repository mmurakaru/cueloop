A comment is feedback attached to marked text. Select the text, type the
comment, and save it. Replies stay with the first comment in a comment thread.

## When the text changes

cueloop uses the quoted text to find a comment after a revision. It only moves
the comment when the match is safe.

If the text no longer matches, the comment stays visible as outdated. cueloop
does not attach it to different text.

## When you send feedback

Your next Message includes new and edited comments. **Comment** sends them and
keeps the Thread open. **Approve** and **Changes** send them with the review
result.

Comments from teammates join the Thread without replacing your comments.

See [Keyboard and mouse](/docs/reference/keyboard/) for marking, commenting, and
replying controls.

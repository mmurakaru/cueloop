Install an integration from the [quickstart](/docs/install/#connect-an-agent).
Each integration uses the same cueloop workflows and review actions.

## Review workflows

| Workflow    | What opens                    |
| ----------- | ----------------------------- |
| `plan`      | a plan                        |
| `reply`     | an agent response             |
| `prototype` | a component design document   |
| `diff`      | working-tree changes          |
| `review`    | pull-request changes          |
| `refine`    | a report from earlier Threads |

## Send a Message

The agent waits while you review. Choose one action when you are ready:

- **Comment** sends new comments and keeps the Thread open.
- **Approve** sends comments and lets the agent continue.
- **Changes** sends comments and asks the agent for a revision.

Comments stay attached to the marked text. Replies form a comment thread.

## Work in herdr

When an agent runs in herdr, cueloop can open the Thread in a herdr tab or
panel. You can choose the target in [Configuration](/docs/reference/configuration/).

For command-line usage, see [Commands](/docs/reference/commands/).

Install your agent integration from the
[quickstart](/docs/install/#connect-your-coding-agent). The integration adds the
same review workflows to Claude Code, Codex, and pi.

## Review workflows

| Workflow    | Opens                                           |
| ----------- | ----------------------------------------------- |
| `plan`      | a plan in the Thread panel                      |
| `reply`     | an agent response in the Thread panel           |
| `prototype` | a component design document in the Thread panel |
| `diff`      | working-tree changes in the Changes panel       |
| `review`    | pull-request changes in the Changes panel       |
| `refine`    | a report built from previous Threads            |

## Send a Message

The agent waits while you review. Choose one action when you are ready:

- **Comment** sends the current annotations and keeps the Thread open.
- **Approve** sends the annotations and lets the agent continue.
- **Request changes** sends the annotations and asks the agent for a revision.

Annotations stay attached to the text you marked. Replies stay grouped with
their original annotation.

## Work in herdr

When you run an agent in herdr, cueloop can open the Thread in a herdr tab or
panel. Configure the target in
[Configuration](/docs/reference/configuration/).

For command-line usage, see [Commands](/docs/reference/commands/).

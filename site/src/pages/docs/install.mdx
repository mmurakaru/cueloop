## Install cueloop

<InstallTabs client:load />

Confirm the installation:

```bash
cueloop --version
```

The installer adds cueloop to your `PATH`. If it cannot update your shell
configuration, it prints the line to add yourself. See
[Configuration](/docs/reference/configuration/) for custom install directories,
version pins, and mirrors.

## Connect your coding agent

Install the integration for each agent you use.

### Claude Code

The Claude Code plugin uses Claude Mod, an experimental feature. Enable function
hooks when you start Claude Code.

```bash
claude plugin marketplace add mmurakaru/cueloop
claude plugin install cueloop@cueloop
CLAUDE_CODE_ENABLE_FUNCTION_HOOKS=1 claude
```

### Codex

```bash
codex plugin marketplace add mmurakaru/cueloop && codex plugin add cueloop@cueloop
```

### pi

```bash
pi install npm:@cueloop/pi
```

## Open your first Thread

Run cueloop with no arguments to open all pending Threads:

```bash
cueloop
```

Open a specific kind of work when you already know what you want to review:

```bash
cueloop plan          # latest pending plan
cueloop diff          # current working-tree changes
cueloop review <pr>   # pull request by number or URL
```

Mark text, add annotations, then send a Message. Approve lets the agent
continue. Comment sends feedback and keeps the Thread open. Request changes
asks the agent for a revision.

## Update cueloop

```bash
cueloop update
```

Restart your agent after updating its integration. Continue with
[The thread](/docs/concepts/thread/) or open the
[command reference](/docs/reference/commands/).

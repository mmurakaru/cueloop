## Share the Thread

Open a plan review and choose **Share**. cueloop copies an SSH command:

```bash
ssh p_7f3k9x2q@cueloop.dev
```

Send that command to your teammate.

## Add annotations

Your teammate runs the command in a terminal. The shared Thread opens with your
existing annotations.

They mark text, add annotations, and choose **Send**. On the first send, cueloop
asks for an optional display name.

## Continue the review

Their annotations appear in your Thread. You decide whether to Comment, Approve,
or Request changes from the agent.

A teammate's send only updates the shared Thread. It never sends a Message to
your agent.

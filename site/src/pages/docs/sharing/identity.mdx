## SSH key identity

The same SSH key maps to the same collaborator across visits. cueloop does not
ask for an email, password, or account.

## Display names

On the first send, a collaborator can add a display name. cueloop remembers the
name for that SSH key. Skipping the prompt leaves the collaborator anonymous.

Each annotation shows its author. Your own annotations keep their normal label,
so you can distinguish local feedback from shared feedback.

## Owner control

A collaborator can update the shared Thread. Only the owner can send a Message
to the coding agent.

## Share

Open a Thread and choose **Share**. cueloop copies a command:

<EmailObfuscationEscape>

```bash
ssh p_7f3k9x2q@cueloop.dev
```

</EmailObfuscationEscape>

Send the command to a teammate. They need an SSH client. They do not need to
install cueloop or create an account.

The share includes the conversation visible when you publish it, including a
Thread whose original artifact is empty. Published conversation text is a
snapshot; sharing again captures later messages. Your teammate can annotate
the original artifact. Thread actions such as star, rename, and delete are
available only to the local owner.

## Comment

Your teammate runs the command, marks text, and adds comments. On the first
send, cueloop asks for an optional display name.

Their comments appear in your Thread with their name. New comments continue to
sync if either side reconnects.

## Send the Message

Only the Thread owner can send a Message to the agent. Review all comments,
then choose Comment, Approve, or Changes.

See [Security and privacy](/docs/sharing/security/) for access, encryption, and
expiration details.

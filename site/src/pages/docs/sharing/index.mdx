Press Share in a plan review. cueloop copies a command like this:

```bash
ssh p_7f3k9x2q@cueloop.dev
```

Send the command to a teammate. They need an SSH client, but they do not need to
install cueloop or create an account.

Your teammate opens the Thread, adds annotations, and sends them back. Their
annotations appear alongside yours with author attribution. Only you can send a
Message from the Thread to your agent.

Continue with [Share a plan](/docs/sharing/quickstart/) for the steps on each
side.

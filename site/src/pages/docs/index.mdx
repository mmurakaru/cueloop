cueloop opens agent work as a Thread. Read it, comment on exact text, and send a
Message back to the same agent conversation.

## Choose a workflow

- `plan` opens an agent plan.
- `reply` opens an agent response.
- `diff` opens working-tree changes.
- `prototype` opens a component design document.
- `review` opens a pull request.

Every workflow uses the same controls. The Thread keeps the work, comments,
replies, and revisions together.

## Start here

1. [Install cueloop and connect an agent](/docs/install/).
2. Ask the agent to open a plan in cueloop.
3. Add comments, then choose Comment, Approve, or Changes.

Next, learn how to [review agent work](/docs/concepts/plan-diff-review/) or
[share a Thread](/docs/sharing/).

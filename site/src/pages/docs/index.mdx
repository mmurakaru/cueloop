cueloop opens agent-authored work as a Thread. Read it, mark the exact text that
needs attention, add annotations, and send a Message back to the agent.

## What you can review

- **plan** opens an agent plan.
- **reply** opens an agent response.
- **diff** opens working-tree changes.
- **prototype** opens a component design document.
- **review** opens a pull request.

Every review uses the same controls and keeps its revisions and annotations
together.

## Start here

1. [Install cueloop and connect your agent](/docs/install/).
2. Learn how [Threads](/docs/concepts/thread/) and
   [annotations](/docs/concepts/annotations/) work.
3. Use the [keyboard and mouse reference](/docs/reference/keyboard/) while you
   review.

To review with a teammate, see [Sharing over SSH](/docs/sharing/).

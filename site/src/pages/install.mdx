cueloop ships as one npm package, `cueloop`, that carries the CLI and the terminal UI.
Releases are alpha, published under the `alpha` dist-tag.

## Install the CLI

```bash
npm i -g cueloop@alpha
cueloop --help
```

## Review a working tree

The fastest way to see a review is over your own uncommitted changes. From inside a git
repository with edits in the working tree:

```bash
cueloop diff
```

This opens a ReviewSession over your working tree, untracked files included. Move with
`j`/`k`, select a span with `v`, comment with `c`, and submit with `Enter`.

## Gate an agent's plan

To review a coding agent's plan before it runs, wire the plan gate as a Claude Code plugin:

```text
/plugin marketplace add mmurakaru/cueloop
/plugin install cueloop@cueloop
```

Now, when the agent leaves plan mode, it blocks on your review. You annotate the plan and
return a verdict; the verdict decides whether the agent proceeds, and your annotations
become the feedback it acts on.

## The grammar, in one line

`j`/`k` move · `v` select a span · `c` comment · `s` suggest · `n`/`p` step through
annotations · `Enter` submit the verdict · `q` quit. Every key is rebindable in
`~/.config/cueloop/config.toml`.

## Develop from source

cueloop is a Bun monorepo that runs from source with no build step.

```bash
bun install
bun test ./packages ./test
bun run examples/1-hello-plan/run.ts
```

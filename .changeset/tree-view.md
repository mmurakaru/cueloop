The rail has a Tree tab that shows the session's history: revisions, comments, checkpoints, and branches, with the path you are on bright and the current tip marked. Option chords and the buttons under it label a checkpoint, start a branch, go to an entry (a switch or a move back with an optional summary), fork the path, and fork-and-share. The thread view shows a moved path in the frame after the key.

Name and manage collaborators. A share viewer is asked for a display name the first time they open a shared plan, so their notes attribute to a name rather than an SSH fingerprint; skipping keeps them anonymous, and a name from a past visit is remembered. The planner can rename any collaborator from the rail (r on a selected note), stored per fingerprint in the user config. The inbox gains a delete action (d, or the [delete] button) behind a centered confirm dialog, so finished plans can be cleared.

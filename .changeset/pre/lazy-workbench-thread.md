A bare `cueloop` launch is now a real workbench: browse the current checkout and your project files freely, and the first comment you leave lazily creates a per-repo thread that persists across restarts and is shareable like any review. Nothing is written to disk until you comment, and the thread is keyed by the repository's identity, so every launch in that repo reattaches to the same workbench.

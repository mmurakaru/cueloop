Render a thread's plan the way a markdown preview does. Headings sit over a rule, links show their label in the link color with the URL tucked away, inline and fenced code gray, and emphasis reads bold, italic, or struck - the source markers are gone. GFM tables render as an aligned grid and leading YAML frontmatter as a bordered key/value table. Comments still anchor to the source under the rendered text, so a note dropped on a link label lands exactly where it reads.
